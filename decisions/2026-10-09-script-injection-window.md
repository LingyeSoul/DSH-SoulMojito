# 决策：剧本注入窗口不含上一块

日期：2026-10-09。状态：已实施（补记偏差）。相关：提案 0014（§2 ST 链路注入「当前±1 块」）、`packages/tavern-store/src/scripts.ts`（formatScriptBlock）。

## Problem

提案 0014 §2 写注入窗口为「按进度取当前±1 块」；实现（`formatScriptBlock`）注入的是**当前块全文 + 下一块 600 字符预览**，不含上一块。scripts.ts 的注释解释了「不做更远剧透」，但没解释为何不带上一块——偏差无记录。

## Decision

维持「当前块 + 下一块预览」并记录理由：

1. **上一块的内容已经在对话历史里**。剧本推进的对齐信号是「本轮正文覆盖当前块的关键事件」（§2 对齐判定），也就是说被推进离开的那一块刚被逐楼层完整演绎过——楼层历史本身就携带了它的全部情节，system 段再注入一份近乎纯冗余。
2. **预算受限下前块挤占当前块**。注入预算固定 2400 字符（`SCRIPT_BLOCK_BUDGET`），三分摊意味着当前块全文被压短——而当前块才是模型唯一无法从历史推断的材料（下一块预览同理只给 600 字符方向感）。
3. 预算算术（head/tail 扣除、`[truncated]` 标注、总长恰 ≤2400）与「末块无 Next 段」等边界由 `tavern-script-play.spec.ts` 的预算用例与端到端用例锁定。

## Alternatives considered

- **按提案补上一块（预算三分摊）**：改 formatScriptBlock + 新增 SCRIPT_PREV_PREVIEW 常量 + 预算用例重基；注入的是历史里已有的信息，token 收益为负。拒绝。
- **上一块只给一行摘要**：摘要从哪来（块首行？关键事件抽取？）引入新的启发式与维护面，收益仍是零。拒绝。

## Consequences

- 提案 0014 §2 的注入窗口描述改为「当前块全文 + 下一块预览」并引用本决策。
- 若未来对齐判定改为非逐字覆盖（例如 LLM 判定跨越多块），上一块的意义会变化，届时重新评估——本决策不构成永久承诺。
