## 盘面几何（第一性）

标准 121 洞六角星不用手工摆盘，用**立方坐标 (q, r, s)（s = -q - r）**的第一性
定义：星形 = 两道大三角形的并集

```
{ q,r,s ≥ -4 }  ∪  { q,r,s ≤ 4 }
```

两三角形各 91 洞（边长 13、角距 12），交叠出六边形 61 洞（坐标三分量全在
[-4, 4]），并集 91+91-61 = **121 洞**。按 r = -8..8 分行、行内 q 升序为列，
自动得到标准星形的 17 行与行洞数 `1,2,3,4,13,12,11,10,9,10,11,12,13,4,3,2,1`；
顶营 = 行 1-4（10 洞）、底营 = 行 14-17（10 洞）。邻接 = 六个轴向单位向量；
跳 = 2× 邻接向量（逾越点与落点都在盘内才入跳表）。

顶点洞 2 邻（六个星尖）、盘心 6 邻——几何不变量由 spec 的全盘扫描锁定
（邻接对称、无自环、无重复、coords 往返）。

**渲染**：pointy-top 六边形像素映射 x = √3·(q + r/2)、y = 1.5·r（unit 画布
22×26、洞径 0.94）；**布局表由引擎模块期注入视图**（`CC_LAYOUT`，与引擎几何
同源零漂移）；预览局面同款模块期由引擎实时生成（地牢爬行纪律的布局化）。

## 规则面裁定（v1）

- **对局**：roles `['red','blue']`，红十子起于顶营、蓝十子起于底营，红先。
- **一手** = 走到相邻空位，**或**跳过紧邻的任意一颗弹珠（不分敌我都是桥）落于
  正后方空位——可连跳、拐弯自由；**同一手不重复落点**（含不得落回起点——
  BFS visited 起手即含起点，防回环是硬保证而非启发式）；无吃子、不吃子不换家。
- **胜负**：先把自己十颗全部搬进对方营盘（十洞全占满）者胜；对方轮到走子而
  无任何合法着法（困毙）同判本方胜（军棋/象棋同款裁决）。无和棋通道。

| 面 | 判定 |
|---|---|
| 121 洞标准星盘 / 十子对营 / 步·跳·连跳（拐弯自由、不重复落点）/ 先满对方营盘胜 / 困毙 | ✅ 实现 |
| 坐标容错（整数串归一执行，2026-10-14 实弹纪律） | ✅ 实现（from/to 两分量都过 parseBoardCoord） |
| 建议集 ≤64（洞号升序 × 步先跳后主序截断，不是合法性依据） | ✅ 实现 |
| 3/6 人局、两营换家/多角变体、限着/计时、和棋判定 | ❌ 不实现（双人桥 v1 恒一人类一 Agent；20 子规模下无实际和棋通道） |
| 投降 | 运行时统一处理（引擎拒 resign 保留动作） |

**坐标与叙述**：动作 `{type:'move', from:[行,列], to:[行,列]}`（0 基二维组，
镜像象棋 from/to 形态）；叙述用 1 基「行-列」名——`红方 4-1 走到 5-5`、
`红方 1-1 跳到 5-7（连跳 3 步）`（连跳步数取 BFS 最小跳数）。

## 困毙判定与可达性论证（如实）

红方被全封锁的理论下界 = **11 颗蓝子**：十子满营时，红方突围面 = 4 个底边子
的 5 个步位（`(0..4,-4)`）+ 对应的 6 个首跳落点（`(-1..4,-3)`），合计 11 格
全部需要蓝子封死；蓝方只有 10 子——**真实可达性未证**（更散的红子分布下界
更高）。判定保留为总函数（任何构造态都不陷入死局），由 spec 的构造性夹具
（红满营 + 蓝 11 子封死 + 1 自由子）锁定行为：红方建议集为空 → 蓝方落子后
判蓝胜（summary「无棋可走」）。

## 机器人 e2e 与两代自纠（如实留档）

引擎级整局收官由「冲家机器人」端到端锁定（129 手红方胜、可重放 deep-equal），
两代失败如实记录：

1. **行贪心**（只推最前排）：双方在 11 行撞墙后无限振荡（快照：`redMaxRow`
   恒定 11、红子永不进营）——「最前排」会被敌墙钉死，整队堵在后面。
2. **车道镜像（按当前位置算家位）**：每颗弹珠的「家」取当前位置的镜像——
   弹珠一移动家就漂到中腹，双方互相圈养进中间一坨（快照：20 子全挤在 5-10
   行、各子「家距」全失真）——**家位必须按弹珠身份在开局一次性分配、随移动
   跟踪**，不能由位置重算。
3. **终态（身份跟踪车道机器人）**：开局镜像配家（顶营 (q,r) ↔ 底营 (-q,-r)）；
   每手按「入家 +1000、家距缩短 ×100、深位家优先（先占远端再回填入口，防
   自我堵门）」排序取第一个未出现的局面签名（打破循环）；只读 legal 决策、
   不复刻合法性。129 手红方终局，整局重放 deep-equal。

## 建议集上限的落点（实测）

真实 20 子局面下红方建议上限实测约 **60**（十子两两相隔 ≥2 时 6 邻居全空 =
60 步；密集中腹簇 49；连跳链会让个别子爆量但总盘仍 ≤60 量级）——**64 的
截断通道在真实局面下到不了**，故截断主序由构造性夹具锁定：12 颗红子两两
相隔 ≥2、六邻全在盘内（候选恰 12×6=72），枚举主序末位的 [8,2] 全部着法被
截断在外但仍可执行（不是合法性依据）；夹具另置一颗蓝活子避免误触发困毙终局。

## 边界（如实）

- **困毙真实可达性未证**（理论下界 11 > 10，见上）——判定分支由构造性夹具
  锁定，真实对局中不会触发；
- **建议集 64 截断**在超密构造局面会隐藏部分落点（视图只读建议集、Agent 以
  建议集为参考）——真实 20 子局面上限约 60，不受影响；
- **无和棋与限着通道**：双方都不进营理论上可无限对弈（无自动判和）——
  泳道式互卡在真实对局中由连跳通道自然化解，未做人工兜底；
- **平衡未评估**：机器人只证明「该局面可终局」，先手优势与两营公平性未做
  数值盲测（对称盘面先手天然占一回合先机，属棋类常态）；
- **视图可读性边界**：121 洞无逐洞坐标文本（hover title + 选中信息行 +
  叙述「行-列」对账替代；六角星全标签会压成噪声）；
- **布局表注入依赖 JS 执行**：无 JS 环境（预览服务端渲染）下棋盘空白——
  与既有内置视图同款边界（全部为脚本渲染）。
