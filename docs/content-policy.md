# 内容边界与使用责任

DSH-SoulMojito 是本地运行的 SillyTavern 兼容角色扮演与内容生产工具，不是内容分发平台。仓库提供软件与格式兼容，不内置面向成人用途的素材。

## 适用范围

- 本工具面向 18 岁及以上用户；未成年人不应使用。
- 禁止任何涉及未成年人的性内容，包括虚构角色、架空设定、外貌或设定暗示未成年、以及年龄不明的角色。
- 禁止非自愿性内容、性暴力、胁迫与剥削题材。
- 禁止把真实人物性化、诽谤或用于骚扰的内容。
- 禁止违反部署所在地法律与模型服务商条款的内容。

## 责任边界

- 模型输出由用户、模型提供方与部署方负责；本项目不审查每一次生成，也不承诺过滤。
- 导入的角色卡、世界书、预设、剧本、聊天记录属于用户数据；导入者负责确认来源、授权与合规性。
- 仓库自带的夹具只用于格式与兼容测试，不含成人素材；公开仓库不接受携带成人素材的 issue、PR 或测试数据。

## 数据边界

- 资产与聊天默认写入 `$DSH_HOME/tavern/`，不随仓库提交，也不由本项目上传。
- 需要分享排错材料时，请先移除聊天正文、角色卡正文与其他可能包含个人或成人内容的字段。

## 兼容标识

- `nsfw` 与 `jailbreak` 是 SillyTavern 预设的兼容槽名，不代表内容豁免，也不改变上述边界。
- 角色卡的 `post_history_instructions` 会按 ST 语义覆盖 `jailbreak` 槽；导入非自建卡前应确认其内容。
- 内置默认预设的 `jailbreak` 内容为空。

## 执行

- `pnpm run check` 运行 `content-lexicon` 闸门，扫描仓库文本与 PNG 文本块，命中词表即失败。
- 如发现仓库内出现违反本边界的素材，请开 issue 或私下联系维护者。
